# Low Poly Procedural Tree Generator — Autodesk Maya

A procedural tree generation tool built with **Python and Autodesk Maya**. The tool generates customizable trees with a tapered trunk, recursively generated branches, and leaves.

## Features

* **Procedural trunk generation** with adjustable height, thickness, and subdivisions.
* **Recursive branching** with controls for branch count, length, size, elevation, and recursion depth.
* **Distribution controls** to influence branch placement along the trunk using mathematical distribution functions.
* **Procedural leaves** to complete the generated tree.
* **Custom Maya UI** for adjusting parameters and generating different tree variations.

## Technologies

* Python
* Autodesk Maya Python API (`maya.cmds`, `maya.api.OpenMaya`)
